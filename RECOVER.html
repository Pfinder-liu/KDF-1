Create NEW Recovery Code

A newly generated Recovery Code cannot recover passwords created with a different Recovery Code.

新码不能恢复使用其他 Recovery Code 建立的密码。旧码遗失时，创建新码不是找回方式。



请抄写、打印或自行保存新码；不要把 Master Phrase 放在同一张纸上。页面不会自动保存，关闭前先保留副本。



QR 不是加密。任何拍摄、复制或扫描此码的人，都取得了这份 Recovery Code。二维码只包含码本身，不包含 Master Phrase 或账户信息。







保存的图片只有二维码。打印时关闭浏览器的页眉和页脚（避免附带标题、路径或日期）；建议至少 45 mm 方形。用系统相机扫描 → 复制文本 → 粘贴到 Recovery Code 输入框。仍可手工输入。
